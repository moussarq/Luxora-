# موقع Luxora Service

موقع فاخر يقدم خدمات تقنية عالية الجودة مع تصميم أنيق وخلفية متحركة.

## المميزات

1. **تصميم جذاب**:
   - ألوان وردية غامقة تميل للبنفسجي
   - خلفية متحركة بتدرجات لونية
   - تأثيرات مرئية متطورة

2. **واجهة مستخدم تفاعلية**:
   - قائمة جانبية تفتح بعلامة + متوهجة
   - صفحات متعددة للخدمات، معلومات عنا، والدعم
   - تأثيرات حركية سلسة

3. **نظام دعم متكامل**:
   - محادثة خاصة بين المستخدم والدعم
   - خصوصية تامة لكل مستخدم
   - إشعارات ورد تلقائي
   - إرسال رسائل إلى بريد المسؤول

## كيفية الاستخدام

1. افتح ملف `home.html` في متصفحك
2. استخدم زر `+` المتوهج في الأعلى لفتح القائمة
3. اختر القسم المطلوب:
   - **الرئيسية**: نظرة عامة مع زر للانتقال للأسفل
   - **خدماتنا**: عرض لجميع الخدمات المقدمة
   - **من نحن**: معلومات عن فريق Luxora
   - **الدعم**: نظام محادثة خاص مع فريق الدعم

4. في صفحة الدعم:
   - اكتب رسالتك في حقل النص
   - سيتم إرسالها إلى بريد المسؤول
   - ستتلقى ردًا تلقائيًا
   - رسائلك خاصة ولا يراها سوى فريق الدعم

## التقنيات المستخدمة

- HTML5
- CSS3 (مع Animations و Flexbox و Grid)
- JavaScript (ES6)
- Font Awesome للرموز
- خط Google Fonts (Cairo)

## كيفية النشر على GitHub

1. أنشئ مستودعًا جديدًا على GitHub
2. ارفع جميع الملفات الأربعة:
   - `home.html`
   - `style.css`
   - `script.js`
   - `README.md`

3. قم بتفعيل GitHub Pages من إعدادات المستودع
4. الموقع سيكون متاحًا على: `https://اسم-المستخدم.github.io/اسم-المستودع/`
